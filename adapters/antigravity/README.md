# Antigravity Adapter

Native adapter for Antigravity CLI and Agent environment.

- **Global Discovery Root**: `~/.agents/skills/`
- **Project Discovery Root**: `<workspace>/.agents/skills/` (and `.agent/skills/`, `.agents/skills.json`)
- **Builtin Skills**: `~/.gemini/antigravity-cli/builtin/skills/` (protected from user writes)
- **Status**: Implemented in skill-manager v3.1.0 / v3.2.0.
